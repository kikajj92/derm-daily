# 문항 검토 기준 — 독립 검토 에이전트용

당신은 문항을 쓴 사람이 아니라 검토자다. 맡은 묶음마다 `work/batches/NN.md`(출제 지시문과 정리본 발췌)와 `work/out/NN.jsonl`(작성된 문항)을 끝까지 읽는다. 사진 묶음이면 지시문에 적힌 `work/img/` 사진도 Read 도구로 직접 연다.

정리본 발췌의 표시: `【…】` 밑줄·형광, `**…**` 굵게, `(23기출)`·`(풀링21)` 같은 표시는 실제 출제됐던 곳. 이 표시가 수험생이 중요하다고 본 출제 포인트다.

## 문항마다 이 순서로 본다

1. **먼저 직접 푼다.** 정답과 해설을 보지 말고 지문과 보기만으로 푼 뒤 정답과 비교한다. 몇 초 만에 확신했다면 4번의 '쉬움'을 의심한다.
2. **정확성 — 교과서로 대조.** 가장 중요한 기준은 「피부과학」 7판 본문이다. 지시문에 붙은 [교과서 원문]과, 필요하면 `work/src/tb/chNN.txt`(단원별 교과서 전문, 스캔 글자 인식본이라 오타가 있음)를 Grep으로 찾아 정답·수치·오답 보기를 하나하나 대조한다. 교과서 기준으로 정답이 하나만 성립하는가? 다른 보기도 맞을 수 있거나, 정답이 틀렸거나, 교과서·발췌와 모순되면 고치거나 버린다. 정리본과 교과서가 다르면 교과서를 따른다. 확실하지 않으면 버린다.
3. **근거.** 정답의 핵심 사실이 발췌의 강조 부분에서 나왔는가? `basis`가 발췌에서 글자 그대로 복사됐는가(【 】·** 기호만 뺀 것)? 아니면 발췌의 강조 부분을 근거로 다시 쓴다. 사진 묶음에서 그 원문항에 [정리본 관련 부분]이 없으면 basis는 빈 문자열이어도 된다.
4. **난이도.** 아래 중 하나라도 해당하면 '쉬움'이다. 같은 근거로 더 어렵게 다시 쓴다.
   - 지문에 진단명이 나오고 그 질환의 가장 유명한 연관 하나를 묻는다.
   - 지문의 단어가 정답 보기에 그대로 있거나, 정답 보기만 유독 길거나 구체적이다.
   - 오답 보기 중 둘 이상이 범주가 달라 바로 지워진다.
   - 정리본을 한 번 훑은 사람이 바로 확신할 수 있다.

   다시 쓸 때: 진단명을 지우고 임상·조직 소견으로 바꾼다. 묻는 것을 진단 다음 단계(원인 유전자·조직·면역형광 소견·치료 선택·금기·수치·예외)로 옮긴다. 오답을 같은 표·같은 계열의 이웃 개념(형제 질환의 유전자, 같은 계열 약의 다른 표적)으로 바꾼다.
5. **쏠림.** 한 묶음에서 같은 질환(또는 같은 기전)을 묻는 문항이 3개 이상이면, 넘치는 문항은 발췌의 다른 강조 부분으로 새로 쓴다.
6. **형식.** 보기 5개가 서로 다르고, `answer`가 정답의 위치(0부터)와 맞고, 해설이 보기를 가)·나)·번호로 부르지 않는가? 사진이 없는 묶음에 "사진", "그림" 표현이 없는가?

## 결과

- 같은 파일 `work/out/NN.jsonl`에 고친 문항까지 전부 JSON Lines로 다시 저장한다. 키와 형식은 원래 그대로 둔다.
- 버린 문항 자리는 같은 지시문의 규칙과 발췌로 새 문항을 써서 채워 줄 수를 유지한다. 새로 쓴 문항도 위 1–6을 통과해야 한다.
